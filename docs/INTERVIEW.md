# 六个常见问题

## 1. QPSK 为什么采用 Gray 映射？

相邻星座位置只差一个 bit。AWGN 下较常见的最近邻判决错误因此通常只造成一个 bit 错误，有利于降低比特误码率。Gray 映射不改变星座几何位置，也不意味着任何错误都只影响一个 bit。

## 2. Eb/N0 和 SNR 有什么不同？噪声方差怎样计算？

Eb/N0 按每个信息比特的能量归一化；SNR 还取决于带宽、比特率，以及离散波形中的采样和滤波定义。不能直接把所有场景的两者视为同一个数。

本项目 Es=1，每符号 k bit，因此 Eb=1/k。令 γb=10^(dB/10)，则 N0=1/(kγb)，每个实噪声分量的方差为 N0/2。BPSK 的 k=1，QPSK 的 k=2。这里没有过采样或波形成形参数。

## 3. 为什么 BPSK 与 Gray QPSK 的理论 BER 一样？

在 AWGN、理想相干接收等假设下，QPSK 的两个正交支路分别进行符号正负判决。按每比特能量比较，两者得到相同的 Q(√(2Eb/N0))，即 0.5 erfc(√(Eb/N0))。这不表示两者的符号误码率也相同。

## 4. 为什么按目标错误数或比特上限停止？

高误码率时，较少样本就能收集到足够错误；低误码率时需要更长实验。双停止条件在精度与计算预算间做折中。代码按块检查，因此可能超过目标错误数。数据依赖的停止规则也意味着展示的 Wilson 区间只是近似描述，不是任意停止时刻有效的置信序列。

## 5. 什么是符号级复基带仿真？省略了什么？

直接计算 I/Q 符号、噪声与判决，不逐采样模拟真实载波。这样可以集中验证调制映射和误码统计。当前省略脉冲成形、匹配滤波、载波与定时同步、编码、多径和真实硬件，不能据此声称完成了实际无线链路。

## 6. 没有错误为什么不能说 BER=0？

错误数除以样本量等于零，只说明这一批样本没有观察到错误。固定 N 的独立二项模型下，单侧 95% 上界为 1−0.05^(1/N)，约为 3/N。它是重复抽样意义下的置信构造，不是“真实参数有 95% 概率低于该值”的贝叶斯概率陈述。

## 项目中的两个工程取舍

- 星座正常点均匀抽样、错误符号全部额外叠加，减少绘图负担并避免遗漏稀有错误。BER 仍按全部比特计算。
- 在线模块版使用 Worker；单文件版使用分块计算并主动让出主线程，避免本地模块或 Worker 加载限制。两种入口共享核心算法，通过一致性测试核对。
