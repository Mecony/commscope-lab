# 模型与实验解释

## 映射、噪声与接收

BPSK：0→+1，1→−1，Q=0。QPSK：比特对 (b₀,b₁) 映射为 `((1−2b₀)+j(1−2b₁))/√2`。四象限标签从第一象限逆时针为 00、10、11、01，相邻标签只差 1 bit。

单位符号能量为 1，Eb=Es/k。令 γb=10^(dB/10)，则 N0=1/(kγb)，复高斯噪声的实部和虚部方差各为 N0/2。BPSK 的虚部噪声用于复基带星座展示，不参与比特判决。

接收端以 I/Q 正负判决。已知相位、定时，不包含同步估计。符号级模型不把过采样采样率误当成符号能量；后续加入波形级模型时必须重新检查能量定义、滤波与采样时刻。

## 文本

UTF-8 字节按最高位优先转换为比特。QPSK 奇数比特序列补一个 0，仅为映射分组；接收端按原长度去掉补位，误码统计也不包含补位。文本本身字节数×8为偶数；随机比特模式可演示奇数长度。

解码器同时检查 UTF-8 有效性并提供替代字符显示。一个 bit 错误可能影响多个可见字符，也可能使字节变成另一个合法字符，因此按比特统计 BER。

## 理论与随机性

JavaScript 使用确定性 Mulberry32 均匀随机数和 Box–Muller 高斯变换。Python 使用 NumPy 默认发生器和独立矢量化信道实现。两种实现都以 SciPy erfc 数值基准和统计容差进行检查，不要求两种 RNG 产生相同样本。

JavaScript 的 erfc 非负参数近似经 −4～14 dB 的 SciPy 基准验证，相对容差 3×10⁻⁶、绝对余量 10⁻¹⁴。

## 扫描、区间与取消

每个调制/SNR 点拥有由基础种子、调制和 SNR 派生的种子。按 10000 bit 分块，目标错误数 200，在块边界检查停止；超过 200 个错误是预期行为。每点最大 200 万 bit，最多 19 个 SNR 点，限制单次任务规模。

Worker 在块间让出执行并报告进度。取消会终止当前 Worker，只保留已经完成的点；CSV 会标记扫描 cancelled/completed/running，包含每点样本数、种子、区间与停止条件，避免把部分结果误认为完整扫描。

非零且非全错误点显示约 95% Wilson 区间。全正确点上界为 `1−0.05^(1/N)`；全错误点下界为 `0.05^(1/N)`。零错误点在对数图上以向下三角标在上界处，不绘制 log(0)。

上述区间不是任意时间有效的置信序列。目标错误数停止策略使 N 具有随机性，不能宣称每次扫描的区间严格覆盖真实值 95%。

## 结果状态

修改单次实验参数后保留旧结果，并明确提示重新运行；图表、链路注释与指标取自该次实际实验的配置。扫描锁定自身参数并保存快照，运行期间修改单次实验参数不影响扫描。
